# 🤖 FutureTech — AI & Future Technologies Showcase

Современный, концептуальный веб-сайт, посвященный искусственному интеллекту и технологиям будущего. Проект представляет собой высококачественную интерактивную верстку, выполненную на чистом технологическом стеке (Vanilla Web Development) с глубоким вниманием к деталям, анимациям и UX/UI.

---

## 🛠️ Стек технологий

Проект разработан без использования тяжелых фреймворков и сторонних библиотек, что обеспечивает максимальную скорость загрузки страниц и чистоту исходного кода:

*   **HTML5:** Семантическая разметка для обеспечения высокой доступности (Accessibility) и SEO-оптимизации.
*   **CSS3 & SASS/SCSS:** Модульная структура стилей, использование CSS-переменных для темизации, Flexbox и Grid Layout для построения сложных сеток.
*   **Ванильный JavaScript (ES6+):** Реализация динамического интерфейса, интерактивных элементов, анимаций и обработки пользовательских сценариев.
*   **Методология:** БЭМ (Блок-Элемент-Модификатор) для обеспечения масштабируемости и изоляции стилей.
*   **Адаптивность:** Полный Responsive/Mobile-First дизайн, оптимизированный под любые экраны (мобильные телефоны, планшеты, ноутбуки, 4K дисплеи).

---

## ✨ Особенности интерфейса и визуализации

*   **Футуристичный UI/UX:** Дизайн вдохновлен технологиями ИИ — темная неоновая палитра, четкие сетки и чистая типографика.
*   **Vanilla JS Effects:** Реализация интерактивных компонентов (табы, выпадающие меню, кастомные слайдеры или аккордеоны) на чистом JavaScript без внешних зависимостей.
*   **Плавные анимации:** Использование CSS transitions & keyframes для создания эффекта погружения в кибернетическую тематику при скролле и ховерах.
*   **Pixel Perfect:** Максимально точное соответствие дизайн-макету из Figma, контроль отступов и адаптивных брейкпоинтов.
*   **Высокая производительность:** Отсутствие фреймворков гарантирует идеальные показатели в Google Lighthouse (Speed/Performance).
